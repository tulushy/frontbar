# 🚀 Frontbar Messenger

Современный веб-мессенджер, вдохновленный дизайном Telegram. Полностью работает в браузере с сохранением данных в localStorage.

## ✨ Возможности

- 💬 Личные и групповые чаты
- 🎨 Дизайн в стиле Telegram (темная тема)
- 📱 Адаптивный дизайн для мобильных устройств
- 💾 Сохранение сообщений в локальном хранилище
- 🔍 Поиск по чатам
- ⌨️ Горячие клавиши (Enter для отправки)
- 🕒 Временные метки сообщений
- 📅 Разделители по датам
- 👤 Аватары с инициалами
- 🔔 Счетчик непрочитанных сообщений
